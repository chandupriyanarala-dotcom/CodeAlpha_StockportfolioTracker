# CodeAlpha_StockportfolioTracker
## Project Description
Stock Portfolio Tracker is a simple Python project that calculates the total investment based on stock name, stock price, and quantity.

## Features
- Enter stock name
- Enter quantity
- Calculate investment for each stock
- Calculate total investment
- Supports multiple stocks
- Simple command-line interface

## Technologies Used
- Python

## Stock Prices Used
- AAPL - 180
- TSLA - 250
- MSFT - 420
- GOOGL - 160

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python stock_portfolio.py
